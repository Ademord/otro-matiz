# Agent recipes

Step-by-step guides for recurring agent jobs that end in an Otro Matiz gallery. Each recipe names the exact commands, the record fields that worked, and the checks to run before handing the file over. A test under `tests/` keeps every recipe's example rendering, so a recipe that stops matching the code fails CI.

| Recipe | Use it when |
|---|---|
| [Product research to gallery](product-research-to-gallery.md) | You verified a shortlist of products (price, fit, stock, photos, shop links) and want to hand over one HTML file with ranked cards |

Keep personal datasets and downloaded photos out of this repository. The worked examples here carry public product facts only and no images; a recipe run happens in a private work folder.
