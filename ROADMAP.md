# Otro Matiz roadmap

This document distinguishes the functionality bundled in this public core from separate product modules and planned work.

## Bundled core

- Generic schema version 2, configurable axes and metadata, legacy project migration.
- Reviewed JSON/CSV import, local image attachment and portable project exports.
- Gallery, Matrix, Favorites, named lists and two-image comparison.
- Decision states, public/private notes and local project management.
- Basic recipient briefs for up to six images and AI handoffs with stable cell IDs.
- Independent image sizing, initially 58%, with readable controls and saved view preferences.
- Continuous minimalist Gallery, independent card titles, configurable scalar specifications and color swatches.
- Full/focused framing, supplied detail images and configurable crop zoom/focal position without image changes.
- Optional row/column grouping, responsive page spacing and explicit portable presentation settings.
- Preservation of imported annotation and brief-design settings in the project model.

## Separate complete workspace

The complete bundle restores the earlier professional shell: advanced brief composition and branding, numbered annotation editing, saved brief versions, project checkpoints/diffs/restoration and exact recipient asset ZIP packages. Those modules now consume canonical rows, columns and generic specifications. Legacy checkpoint archives remain intact and restore into independent schema-v2 copies. Checkpoint comparisons include saved presentation settings.

The shell embeds this core through a same-origin iframe and its existing integration hooks. These editing and history interfaces are included in the complete bundle's `premium-app` directory, not in the standalone core. Basic core briefs omit numbered annotations. Visual acceptance is recorded separately from the build checks in the task acceptance evidence.

## Planned capabilities

- Per-image framing overrides beyond the current project-wide crop settings.
- Prototype account-connected planning and image-result transfer to stable cell IDs; automatic model execution is not implemented.
- Database-server connections and native database-file adapters; current imports accept export files only.
- Hosted sharing, accounts, teams and billing after validating the local workflows.

Source licensing remains undecided. The repository includes CI and GitHub Pages workflows; publication is confirmed by the corresponding successful repository and deployment operations.
